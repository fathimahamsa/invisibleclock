# Invisible Cloak using OpenCV

This project creates an **invisibility effect** by detecting a red-colored cloth and replacing it with the background, making the person appear invisible. The effect is achieved using color masking in HSV space and blending the background with the live frame.

---

## 🚀 Features
- Real-time invisibility effect  
- Detects red-colored cloak using HSV color masking  
- Automatically blends the background  
- Works smoothly with a webcam
